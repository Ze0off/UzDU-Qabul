Loyiha maqsadi: Ushbu kurs ishi universitetga qabul jarayonini to'liq raqamlashtirishga qaratilgan. Platforma orqali abituriyentlar ro'yxatdan o'tishi, tizimga kirishi va ariza topshirishi mumkin. Arizada shaxsiy ma'lumotlar, pasport ma'lumotlari va tanlangan yo'nalish ko'rsatiladi.

Admin panel orqali barcha arizalar ko'rib chiqiladi, qabul yoki rad etiladi. Tizim HTML, CSS va JavaScript texnologiyalari yordamida yaratilgan bo'lib, ma'lumotlar localStorage'da saqlanadi.
